# FungiDB MATpredict

This project runs [MATPredict](https://github.com/stajichlab/MATPredict) on
FungiDB genomes and compares the mating-type (MAT) locus genes it finds with
the genes annotated in the matching FungiDB GFF files.

- Source code: <https://github.com/hyphaltip/FungiDB_MATpredict>
- Task description: [TASK.md](https://github.com/hyphaltip/FungiDB_MATpredict/blob/main/TASK.md)
